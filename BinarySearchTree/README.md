# Binary Search Tree

This implementation is based on concepts and examples from:

Lysecky, R., & Vahid, F. (2018, June). _C950: Data Structures and Algorithms II_. zyBooks.

The original implementation has been adapted and modernized to incorporate current Python practices, including type hints, documentation, improved naming conventions, and code organization.

## Features

- Inserts unique integer keys
- Searches for keys
- Removes leaf, one-child, and two-child nodes
- Calculates tree height
- Performs in-order traversal
- Produces an ASCII-art tree representation

## Running the Example

From the project root:

```text
python -m BinarySearchTree.main
```

The command above assumes the project is executed from the repository root with `BinarySearchTree` available as a package. Based on its package-qualified imports, it needs to run with the project root on Python’s import path.
